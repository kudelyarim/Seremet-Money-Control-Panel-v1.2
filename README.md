# Seremet Money Control Panel

Personal Finance Management Application | Kişisel Finans Yönetimi Uygulaması

-----English------

A desktop application developed with Python and Tkinter to help users manage income, expenses, assets, and notes in one place.

Technologies: Python, Tkinter, SQLite.

-----Türkçe-----

Gelir, gider, varlık ve notları tek bir yerde yönetmek için Python ve Tkinter ile geliştirilmiş bir masaüstü uygulamasıdır.

Teknolojiler: Python, Tkinter, SQLite.


Developer: İlker Şeremet

Project: Seremet Money Control Panel

Built with Python, developed through continuous learning.

Sürekli öğrenme ve geliştirme anlayışıyla Python kullanılarak geliştirilmiştir.
